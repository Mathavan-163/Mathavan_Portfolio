# Mathavan Modern Portfolio

A modern React + Vite developer portfolio using:

- React
- Bootstrap 5
- GSAP + ScrollTrigger
- Motion
- Lenis smooth scrolling
- Lucide React
- Custom CSS
- Responsive design

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
npm run preview
```

## Customize

Main content is in `src/App.jsx`.
Theme and animations are in `src/styles.css`.

Replace `public/resume.pdf` with your actual resume PDF.

Update:
- GitHub URL
- LinkedIn URL
- email
- phone
- project live URLs
- certificate details

The design uses only:
- #000000
- #5fe442
- rgba(95, 228, 66, 0.12)
- white / white opacity for text and UI
